# Historical implementation material

The specifications and plans in this directory record earlier design and
implementation work. They are retained for provenance and may contain old
commands, paths, schemas, feature names, or behavior that the current runtime no
longer exposes.

Do not use this directory as product documentation. Start at
[`docs/README.md`](../README.md), use the generated
[CLI reference](../reference/cli.md) for commands, and verify current behavior
against the active architecture pages.
